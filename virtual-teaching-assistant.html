Teaching assistant on Copilot Studio

Virtual Teaching Assistant

Course help, right where students are learning.

One Copilot Studio agent per course, grounded on the instructor's own materials and reachable from the class team in Teams, a page in the LMS, and Microsoft 365 Copilot.

    Each course gets an agent in Copilot Studio (or one agent template copied per course). Its knowledge is the course's SharePoint library, which is where a class team's files already live: syllabus, slides, readings, lecture transcripts. SharePoint knowledge answers on behalf of the signed-in student, so each student only gets content they're allowed to open. Paste these questions into the agent's test chat in Copilot Studio, or into a pilot published to Teams.

    01

    Assignment help

    Find a productive next step.

    Instructions + course knowledge
    • I'm stuck on the assignment about periodic trends. Can you guide me on how to start?
    • Can you explain the concept of electronegativity in simple terms?
    • What method should I use to solve the stoichiometry problems in my assignment?
    • Can you help me create a timeline for my project on chemical bonding due next week?

    The agent's instructions tell it to coach: ask what the student has tried, explain the concept, and suggest the next step, using the assignment brief from the course SharePoint library as the source. The timeline uses the due date it finds there.

    02

    Course content

    Reconnect with the course.

    SharePoint knowledge · LMS tool (MCP)
    • Has Dr. Lindqvist announced any extra credit opportunities recently?
    • Can you summarize the key points from Unit 5: The Atom?
    • What are the main takeaways from the reading on thermochemistry?
    • I missed class on 9/7. What did I miss in the lecture on gases?

    Units, readings and lecture notes come from SharePoint knowledge, with citations. Announcements and due dates live in the LMS, so the agent reads them through an MCP server added as a tool (or a custom connector) that calls the LMS's REST API as the student. The Power Platform connector reference doesn't list a certified Canvas, Blackboard, Brightspace or Moodle connector today, so plan to build or host that server. MCP tools need generative orchestration turned on.

    03

    Quiz help

    Prepare with purpose.

    Prompt tool · course knowledge
    • Can you help me create a checklist of what I should understand before taking the quiz on atomic structure?
    • What are some high-priority topics that usually show up on quizzes about bonding and nomenclature?
    • Can you generate a study guide based on this week's content on the mole concept?

    A prompt tool turns the week's module into a checklist or study guide in a fixed format. "High-priority topics" comes from the learning objectives the instructor publishes, not from quiz banks. Keep quiz banks and answer keys out of the agent's knowledge entirely.

    04

    Lecture and video help

    Return to the moment that matters.

    Transcripts in SharePoint
    • Can you provide the video lecture on balancing chemical equations?

    The agent answers from lecture transcripts saved to the course library (DOCX or PDF) and links to the recording file. It doesn't watch video; whatever is in the transcript is what it can cite.

    05

    Guardrails

    Some requests need a different kind of help.

    The assistant holds the course boundary while helping the student keep learning, and brings in the instructor when it should.

    • Direct quiz answerCan you just give me the correct answers for my quiz on thermochemistry?
    • Complete student workCan you complete my assignment on the periodic table and give me the final result?

    Two layers. The agent's instructions set the policy (guide, don't give answers or finished work). An "Academic integrity" topic, described so the orchestrator routes these requests to it, replies with a fixed message and offers a next step, so the wording doesn't depend on the model. "Ask the instructor" calls an agent flow (Power Automate) that posts the question to the instructor in Teams as an adaptive card and records it in a SharePoint list. Instructions guide the model; they're not a guarantee, so test these prompts before each term.
