01 WHAT DO YOU NEED

Pick everything you are interested in.

Each step adds to the same Copilot Studio agent. The use-case agents (Teaching assistant, Retention, Recruitment, Advising, Student services, Financial aid, Transfer credit, Careers, Research admin, Campus operations, Alumni) are separate agents and can be priced on their own.

There is no Campus Copilot licence. Everything here is Microsoft list pricing: Copilot Studio agents consume Copilot Credits, bought as prepaid capacity packs, a one-year pre-purchase plan, or pay-as-you-go through an Azure subscription linked by a billing policy in the Power Platform admin center. Makers need a Copilot Studio user licence ($0, with a capacity pack), the Copilot Studio author role (pay-as-you-go or pre-purchase), or a Microsoft 365 Copilot licence. Data Bridge adds a Fabric capacity (F2 or larger) for the Fabric data agent. Partner build and onboarding services are not included.

02 ABOUT YOU

Only what your selection needs.

Microsoft 365 Copilot (rebranded Microsoft Copilot in August 2026) licensed users who use an agent in Copilot Chat, Teams or SharePoint under their own signed-in identity are not charged Copilot Credits for employee-facing scenarios, subject to fair-usage limits. This covers agent flows only when the "When an agent calls the flow" trigger is used. Autonomous (event-triggered) runs, public website visitors and Computer-Using Agents always consume credits. The builder treats students as unlicensed, so the estimate stays on the safe side.

03 THE DETAIL

A few follow-ups per product.

Each conversation is priced by what the agent does in it. Classic answer (an authored topic message): 1 credit. Generative answer: 2. Agent action (a tool, connector, MCP tool, trigger or topic transition on the activity map): 5. Tenant graph grounding: 10 per grounded message. Agent flow actions: 13 per 100. Prompt tools: basic 1 and standard 15 per 10 responses. Reasoning models add 10 credits per 1,000 billed tokens. Open the activity map in the test pane to count your own agent's steps, or use Microsoft's Copilot Studio agent usage estimator.

04 VOLUME

What each tier costs.

Copilot Credit rates (Microsoft list)

Rates apply to all language models Copilot Studio provides. Bring-your-own Azure AI Foundry models are billed separately in Azure.

Prepaid capacity packs are pooled across the tenant and can be allocated per environment in the Power Platform admin center (Licensing → Copilot Studio). Unused credits don't carry over to the next month. If prepaid usage reaches 125%, agents in environments without pay-as-you-go are blocked. Agent flows are blocked separately. Admins can set a monthly limit for each agent.
