01 THE REACH GAP

Six counselors. Eleven thousand students. Prep goes to whoever books first.

Resume feedback before a first application

Illustrative figures · not product output · one dot ≈ 10 students

The numbers are illustrative. The point is equity: today, prep goes to students who know to book early, which tends to skew away from first-generation and transfer students. One Copilot Studio agent, published to Microsoft Teams and to the career centre website with Microsoft Entra ID sign-in, gives every student a first pass at any hour. Usage is billed to the institution in Copilot Credits, so students need no personal AI subscription. Counselor time then goes to the conversations that need a person.

02 RESUME FEEDBACK

Feedback on the draft. The words stay the student's.

Coaching mode · set by the career office

PDFjonah-mbeki-resume.pdf · uploaded in Teams
Target roleData analyst intern

      Fictional student · the rubric is the career office's own · illustrative output

      A "Resume review" topic asks for the file with a Question node set to Identify: File (or reads First(System.Activity.Attachments) if the student already attached it). File uploads must be on (Settings → Generative AI → File uploads); they work in Teams and the website channel, not the SharePoint channel, and encrypted or sensitivity-labelled files can't be read. The topic passes the file to an agent flow that calls Run a prompt: a prompt whose instructions hold the office's rubric and coaching mode and which returns JSON. Calling it through an agent flow is deliberate, because document input isn't yet supported for prompts added directly as tools. Prompt document input takes PDF, PNG and JPG; Word files need code interpreter on in the prompt settings. The coaching mode is a line in the prompt instructions, a design choice rather than a product switch. Nothing is stored unless the student chooses to save it.

      03 INTERVIEW PRACTICE

      Practise at midnight. Arrive at the real one having said it out loud once.

      TEAMS · 1:1 WITH CAMPUS COPILOTText role-play

      Text Q&A role-play · illustrative conversation

      An "Interview coach" child agent inside the main Copilot Studio agent, with its own instructions: ask one question at a time, wait for the answer, give feedback on structure (situation, task, action, result) and specifics, never rate the student as a candidate, and point to a counselor for anything about a live offer. It's text role-play in the chat. Practice notes are written to a Dataverse table only after the student says yes in the conversation, and only that student and staff they choose to share with can read them (row-level security in Dataverse).

          Listings come from the institution's own job board. The connector reference has no certified connector for the common campus job-board platforms (checked November 2026), and the LinkedIn V2 connector only posts content, so if the vendor offers an API, wrap it in a custom connector or an MCP server. Listings the office curates itself can sit in a Dataverse table or SharePoint list. If employers publish on Eventbrite, that connector's "When an event is created (V2)" trigger can feed the list.

          05 A COUNSELOR WHEN IT MATTERS

          The agent knows when to hand over, and the counselor arrives briefed.

          The agent suggests a person when

            Illustrative flow · fictional counselor and student

            The Microsoft Bookings connector can't create an appointment for a student: it offers triggers (When a appointment is Created, Updated or Cancelled) and one admin action that lists booking businesses. So the agent shares the counselor team's Bookings page link and the student books there. A cloud flow on "When a appointment is Created" matches the student by email in Dataverse and, only if the student agreed in chat, posts a prep pack (latest resume review and practice notes) to the counselor in Teams; it sends the student a short checklist. Updated and Cancelled triggers keep the record current. The connector page says a Bookings licence is needed.

            06 HOW IT'S BUILT, AND WHO DECIDES

            One agent, a few tools, and a person at every decision.

            Who decides

            Connector names checked against the Power Platform connector reference · November 2026

            Students sign in with Microsoft Entra ID, and every tool that reads student data runs with the signed-in user's identity, so a student sees only their own records. Staff use is limited to an Entra ID security group. Admins set the environment and data loss prevention (DLP) policies in the Power Platform admin center; Microsoft Purview audits agent activity; Copilot Studio analytics shows sessions, outcomes and satisfaction. Any tool that writes to a record has "Ask the end user before running" turned on. Retention of resumes and notes follows the institution's records policy.
