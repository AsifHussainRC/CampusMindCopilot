        File input: Copilot Studio lets users attach images (JPG, PNG, WebP, GIF, up to 15 MB) in Teams and on the website channel, not on SharePoint. The agent can read the photo to suggest a trade, and the student confirms it. A topic takes the file from First(System.Activity.Attachments) and passes contentBytes and name to an agent flow (Learn: "Pass files to agent flows, connectors, and tools"). ServiceNow: the ServiceNow connector's Create Record and "Upload a binary file as an attachment" actions, against the facilities table your instance uses. Dynamics 365 Field Service: work orders are Dataverse rows, so the flow uses the Microsoft Dataverse connector's "Add a new row" on the Work Order table. Another CMMS: a custom connector over its REST API, or an MCP server if the vendor ships one. Status updates: the ServiceNow connector has no "record changed" trigger, so a scheduled cloud flow polls List Records (or ServiceNow calls a flow over HTTP). For Field Service, the Dataverse trigger "When a row is added, modified or deleted" fires instead. The flow posts back with the Teams connector's "Post message in a chat or channel", posting as the Copilot Studio agent, which needs the agent installed for that user.

        03 ROOMS AND EVENT SETUP

        "A room for 24 on Thursday, with a projector" takes one message.

        People

        Needs

        Event setup

        THURSDAY 19 NOVEMBER · 14:00–15:30

            Fictional rooms · Illustrative · not product output

            Rooms are Exchange room mailboxes, grouped into room lists. The agent uses the Office 365 Outlook connector: "Get rooms in room list (V2)" to list candidates (Get rooms (V2) returns at most 100), "Find meeting times (V2)" with the rooms as resource attendees to check availability, and "Create event (V4)" with the chosen room to book it. The room mailbox's own booking policy still decides whether it accepts. Capacity, step-free access and equipment come from room metadata you keep in Dataverse, or in Microsoft Places if you use it (Places core room booking is included in A1/A3/A5; check-in and auto-release need per-space licensing). The agent books through the room mailboxes that Places also uses; it doesn't call Places directly. Event setup isn't a booking. It becomes a request to the events team, created by an agent flow, and staff approve anything with a cost.

            04 QUICK ANSWERS, URGENT ISSUES

            Parking and dining get an answer. Smoke gets a phone number and a person.

            Example numbers and URLs · Use your institution's real campus safety number

            FAQs: the campus parking, transport and dining pages are added as public website knowledge sources, so answers are generated from them and come with citations. Emergencies: a dedicated topic ("Emergency – call campus safety") whose description and trigger phrases cover fire, smoke, gas, injury and threats. It sends a fixed Message node, not generated text, and ends there. The agent's instructions also say never to troubleshoot an emergency. Topic detection can't be guaranteed, so the website and Teams welcome message shows the safety number too. Urgent but not life-threatening issues, such as water coming through a ceiling, go to the Escalate system topic. It gives the on-call number, and an agent flow posts a card to the on-call channel with the Teams connector's "Post card in a chat or channel". If you use Dynamics 365 Customer Service or ServiceNow for live chat, add a Transfer conversation node to Escalate so the person sees the full history.

              The Fabric data agent is added to a separate manager-facing Copilot Studio agent as a connected agent (preview). It's validated only in Microsoft Teams, not in Microsoft 365 Copilot. Use user authentication so each manager sees only the buildings they're permitted to see. Data: Fabric Data Factory's ServiceNow connector copies work orders into a lakehouse, or for Field Service, Link to Microsoft Fabric brings in Dataverse. Sensors: IoT data flows into an Eventstream, and an Activator rule watches it. Activator "custom actions" call a Power Automate flow (Learn: "Trigger custom actions"). The flow creates the work order with source "sensor" and posts to the on-call channel. A technician triages it, and nothing is closed automatically.

              06 HOW IT'S BUILT

              One agent in front. The systems you already run behind it.

              Every connector named on this page is in the Power Platform connector reference: ServiceNow (Create Record, Upload a binary file as an attachment, List Records), Office 365 Outlook (Get rooms in room list (V2), Find meeting times (V2), Create event (V4)), Microsoft Teams (Post message in a chat or channel, Post card in a chat or channel), and Microsoft Dataverse (Add a new row, When a row is added, modified or deleted). ServiceNow is a premium connector, so the flows need the matching Power Automate licensing, or agent flows billed as Copilot Credits. Generative orchestration must be on for the agent to choose tools and connected agents by their descriptions.

              07 PEOPLE IN CONTROL · OUTCOME

              The agent writes things down. People dispatch, approve and close.

                Outcome one term, illustrative

                Illustrative figures · not product output

                Tools that change a record (create work order, book a room, create an event request) have "Ask the end user before running" turned on, so the requester confirms every one. Dispatch, priority changes, spending approvals and closing a work order stay in the facilities system with staff. Users sign in with Microsoft Entra ID on Teams and on the authenticated website channel, so each requester sees only their own requests. The flow looks up work orders by the signed-in user's email, never by a number they type. Keep request records and photos according to your institution's records-retention policy. Admins: Power Platform admin center (environments, DLP keeps the ServiceNow connector in the right group), Copilot Studio analytics (sessions, escalations, CSAT), Microsoft Purview audit, and Copilot Credits consumption.
