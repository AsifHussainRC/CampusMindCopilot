CAMPUS CHAT LAB

01 EVERYONE, OR NOBODY

AI shouldn't be something you can afford.

Individual subscriptions sort a campus by who can pay $20 a month. A Copilot Studio agent published to Microsoft Teams is open to anyone signed in with an institutional Entra ID account. Usage is billed to the institution through Copilot Credits (prepaid capacity packs or pay-as-you-go), so a student does not need a personal AI subscription or a Microsoft 365 Copilot licence to chat with it.

02 EVERY MODEL

Not one vendor. Several.

One Microsoft agreement. No separate contract per model vendor.

The agent's main model is picked on its Overview page. GPT Chat Latest is the default and follows the newest supported GPT chat model. Claude Sonnet 4.6 and Claude Opus 4.6, 4.7 and 4.8 are generally available once an admin turns on external models (Power Platform admin center) and allows Anthropic (Microsoft 365 admin center). Mistral (preview) and Grok 4.2 (experimental, early-access environments in the US) are external models that aren't meant for production. Prompt tools can also connect Azure AI Foundry models such as Llama and DeepSeek. Models marked cross-geo may process data outside your region.

03 RIGHT MODEL, SAME THREAD

Change model. Keep the conversation.

One thread. The context carries from step to step.

Users don't pick models in chat. The agent's generative orchestration does it, sending each step to the agent or tool whose description fits. Here an Editor agent running on Claude Opus 4.8 checks the main agent's GPT Chat Latest draft, and a prompt tool connected to Llama in Azure AI Foundry summarises the result. Conversation history and variables carry across, so nobody copies text between tabs.

04 BRING PEOPLE IN

A conversation, not a private tab.

TEAMS GROUP CHAT1 participant

When publishing to the Teams channel, turn on the option that lets the agent be used in group and meeting chats. People then add the agent to a group chat and @mention it. Everyone shares one thread and one history in Teams, so the work doesn't sit in somebody's private account.

05 MESSAGE MODE

Leave the agent out. It can still catch up.

In a Teams group chat, the agent only receives messages that @mention it, so people can talk among themselves without it. When someone @mentions it, a topic runs an agent flow (Power Automate) that reads the recent chat messages through Microsoft Graph and gives them to the agent. It then answers using what was decided while it was quiet.

06 ONE PLACE

Nobody leaves the chat.

On every answer

Knowledge (web, SharePoint), tools (MCP servers, connectors, agent flows), connected agents (Fabric data agent) and topics all sit behind one chat. The orchestrator chooses which one to use based on each one's description. Thumbs up or down sends feedback to Copilot Studio analytics, and "Start over" resets the conversation.

07 HOW IT'S BUILT

One agent. Everything behind it.

Microsoft 365, Power Platform and Fabric, already licensed by most campuses.

Microsoft validates a Copilot Studio agent with a connected Fabric data agent only in Teams; it isn't supported in Microsoft 365 Copilot yet, so publish to Teams. With user authentication, each person sees only the Fabric data they're already allowed to see. Admins control model access, data loss prevention (DLP) and environments in the Power Platform admin center.
