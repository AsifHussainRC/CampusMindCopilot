      06 SPEND

      One pool of credits. Four places to cap it.

      Open the Power Platform admin center

      Power Platform admin center > Licensing > Copilot Studio (the Copilot hub has the same credit and capacity views). Prepaid Copilot Credits are pooled across the tenant. Manage capacity sets each environment's allocation and its overage source: unallocated tenant capacity (the default when no allocation is set), a pay-as-you-go billing policy linked to an Azure subscription, or neither. Manage agents sets a monthly limit per agent, with notifications and an optional hard stop. If an environment draws on the pool and the tenant reaches 125% of prepaid capacity, its agents are blocked, even mid-conversation. An environment with credits left in its own allocation isn't blocked. Agent flows are checked separately: new runs stop only when the environment has no credits. Limits take effect after a delay, not instantly. There is no per-user credit cap; control people with sharing and security groups.

      07 OBSERVE & PROTECT

      A file tells the agent to leak. What stops it?

      Where the signals live

      Included: Copilot Studio analytics per agent; Application Insights telemetry; Purview audit of maker and admin activity, with Microsoft Sentinel alerts on the same events; the Protection status column on the Copilot Studio Agents page (Protected, Needs review or Unknown across Authentication, Policies and Content moderation); the automatic security scan before publish; sensitivity labels shown for SharePoint knowledge; the quarantine API. Agent 365: Agents > Overview and observability telemetry, Agent Map, Purview for agent interactions (DSPM with AI observability, auditing, DLP, Insider Risk Management, eDiscovery, data lifecycle management; it covers agent-to-human, human-to-agent, agent-to-tool and agent-to-agent), and Defender real-time protection for Copilot Studio. Defender: Defender portal > Settings > Security for AI > Get started, done by a Security Administrator; a Power Platform admin finishes Copilot Studio setup. It scans tool invocations, detects suspicious behaviour and cross-prompt injection, blocks the response and raises an alert or incident. Alerts need the Microsoft 365 connector; blocking works without it. Quarantine: POST …/SetAsQuarantined in the Power Platform API; makers can still test, no other channel works. The incident is illustrative.

      08 ROLES

      Same agents. Different powers.

      Power Platform Administrator, AI Administrator, Security Administrator and Global Administrator are Entra roles. Environment Maker, System Administrator and Bot Transcript Viewer are Dataverse security roles in each environment. Editor, Viewer and Analytics Viewer are sharing roles on each agent. In the Microsoft 365 admin center, approving agent requests and assigning owners need the AI Administrator or Global Administrator role; pinning needs AI Administrator. Agent Map needs Global or AI Administrator (and E7/Agent 365). The quarantine API accepts Global, AI or Power Platform Administrators. Defender security for AI is onboarded by a Security Administrator, with a Power Platform admin completing Copilot Studio real-time protection. The Copilot Author setting limits who can build agents.
